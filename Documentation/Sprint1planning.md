## Sprint Goal

The goal of Sprint 1 is to organize the CareerConnect project, complete the required planning and documentation, define the main system features through user stories, and begin development of the first basic features.

By the end of the sprint, the team plans to demonstrate user registration and login, along with resume upload.

## Effort Estimation

The team will use story points to estimate work.

- 1 point: very small task
- 2 points: small task
- 3 points: medium task
- 5 points: larger task
- 8 points: complex task that may require work from several members

The estimates may change if the team finds that a task is larger or smaller than expected.

## Sprint Risks

| Risk | Possible Problem | How We Will Handle It |
|---|---|---|
| Different schedules | Team members may not be available at the same time | Use GitHub, the project board, and team communication to stay updated |
| Tasks take longer than expected | Some work may be delayed | Focus on the required Sprint 1 deliverables and basic demo features first |
| Git conflicts | Changes may conflict when several members work on the repository | Use branches, pull requests, and code review |
| Unclear requirements | Work may need to be changed later | Discuss unclear requirements before implementation |
| Limited time before the deadline | Some work may not be completed on time | Monitor progress regularly and prioritize required work |
| AI-generated errors | AI output may contain incorrect information or code | Review, test, and validate AI-assisted work before using it |
